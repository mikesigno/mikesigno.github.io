How I build

Custom boards for every project

I design a dedicated PCB for each project, so every circuit is tailored to the exact features it needs and fully optimised for the dimensions and specification of the unit. Once finalised, the circuits are built on professionally manufactured boards.

Custom front panels

Each project comes with a custom designed front panel in stainless steel or aluminium. Panels can be screen printed or laser etched in any colour to match the design.

Design philosophy

I want to build things the way they used to be built, with care, durability and respect for the craft: modular, serviceable and made with quality parts, like the legendary equipment that was built like a tank, so that everything I make stands the test of time.
