About

A replica of the SL691, the studio computer of the SSL 4000: the hardware recreated in a virtual machine, running the same code as the original.

You can try it in your browser. The test drive runs the standard G Series program (G4.01) with a test reel loaded, with the keyboard, faders and a quick guide to the main commands. It works best on a computer.

Specifications

  • Replica of the SSL SL691 studio computer, running the original code in a virtual machine
  • 3U 19" rack unit
  • Fader connectors for up to 80 faders in groups of 8, plus VCA groups 1 to 8
  • Keyboard connector
  • LTC timecode in and out on XLR
  • Video on HDMI, plus RGB and composite on BNC
  • Tape machine connector
  • Service USB and IEC mains inlet
