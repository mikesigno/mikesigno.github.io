Resources downloads
Page: https://mikesigno.github.io/resources.html

Files in this folder are listed under Downloads on the Resources page.
The title comes from the file name: Neve-1073-Schematic.pdf shows as "Neve 1073 Schematic".
A double dash adds a colon: Tape-Alignment--Level-and-Bias-Reference.pdf shows as
"Tape Alignment: Level and Bias Reference". A number at the start (01-, 02-) sets the order and is not shown.
To update a file, upload the new version with exactly the same name.
Files bigger than 25 MB can't be uploaded through the GitHub website: ask for a link instead.
